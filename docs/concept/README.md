# Space Game context bundle

Everything from the concept phase (11 Oct 2026), packed for the development VM.

1. Copy this folder into the VM, for example as `~/space-game/docs/context/`, or use it as the start of the project folder.
2. Start Claude Code in that project and tell it: "Read CLAUDE.md in the context folder, then start the spike."
3. If you put the folder somewhere other than the project root, add one line to the project's own `CLAUDE.md` that points to it, so every session finds it.

Open `boards/concept-board/concept-board.html` in a browser for the interactive concept board. The fonts load from Google Fonts when online, and fallbacks are used offline.
