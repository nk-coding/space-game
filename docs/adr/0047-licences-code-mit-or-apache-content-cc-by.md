# ADR-0047: Licences: code MIT OR Apache-2.0, content CC BY 4.0

- Status: Accepted
- Date: 2026-10-20
- Decided by: Niklas
- Related: [ADR-0008](0008-local-git-only.md), [ADR-0021](0021-no-fixed-raster-graphics.md), [ADR-0028](0028-icons-in-the-content-pack.md), [ADR-0039](0039-vitepress-wiki-from-game-data.md), [ADR-0048](0048-the-web-build-is-a-player-platform.md), `LICENSE`, `THIRD_PARTY_NOTICES.md`, `docs/client.md` "Licences and third-party notices"

## Context

Niklas wants the repository ready to publish. A read-only IP audit (20 Oct 2026) found no violations, only gaps: the
workspace said `license = "UNLICENSED"`, there was no licence file, no notices file for the dependencies and fonts the
builds carry, no notice on the wiki's modified VitePress components, no README and no statement of how the project is
made (mostly by AI agents under Niklas's direction).

## Options considered

- **One licence for everything** (e.g. MIT for all files): reason not recorded; a code licence fits game data, lore,
  icons and prose poorly.
- **Code MIT OR Apache-2.0, content and art CC BY 4.0** (chosen): the Rust norm for code (dual, the user picks), a
  standard attribution licence for the creative parts.

## Decision

- **Code** is under **MIT OR Apache-2.0** (`LICENSE-MIT`, `LICENSE-APACHE`): the Rust crates (`crates/`), the
  scripts and tools (`scripts/`, `.github/`, `.claude/settings.json`), the wiki's code (`wiki/.vitepress/`,
  `wiki/scripts/`, `wiki/package.json`), the build files (Cargo, Trunk, `index.html`). `Cargo.toml`'s
  `[workspace.package]` and `wiki/package.json` say `MIT OR Apache-2.0`; `publish = false` stays.
- **Content and art** are under **CC BY 4.0** (`content/LICENSE`): everything under `content/` (data, text, lore, the
  SVG icons), `art/tokens.json` (the style tokens are art direction: the palette and the look's constants, the
  numbers behind `docs/style-guide.md`, even though the `art` crate compiles them in; lead's reading of Niklas's
  split), the docs and their screenshots (`docs/`, `README.md`, `CLAUDE.md`) and the wiki's prose (its Markdown pages,
  `nav.json`, `public/`).
- **Not ours, keeping their own licences**: the fonts (Barlow, OFL 1.1, `crates/client/kit/assets/fonts/OFL.txt`;
  Fira Mono, Hack, Ubuntu Light, Noto Emoji and emoji-icon-font inside dependencies), the modified VitePress
  components in `wiki/.vitepress/theme/overrides/` (MIT, `LICENSE-vitepress` there, a header comment in each) and the
  dependencies (`THIRD_PARTY_NOTICES.md`).
- The copyright holder is written "Niklas", the form the repo already uses (`content/base/pack.ron`'s `authors`).
  `pack.ron` gets no `license` field: the manifest schema (`PackManifest`, `deny_unknown_fields`) has none, and adding
  one is a code change for later.

The audit's findings, and what this change does about each:

- **Dependency licences are fine**: every crate in the web and desktop builds is under a permissive licence (MIT,
  Apache-2.0, Zlib, BSD, ISC, Unicode-3.0, CC0, MIT-0) or MPL-2.0 (`smartstring`, used unmodified, source on
  crates.io); the egui fonts add OFL-1.1 and the Ubuntu Font Licence. Nothing copyleft beyond MPL's per-file terms.
- **Notices**: `THIRD_PARTY_NOTICES.md`, generated by `scripts/third-party-notices.sh` (cargo-about,
  `scripts/notices/`), with the fonts, MPL, Unicode and BSD notes and the wiki's bundled npm packages by hand in its
  template. Regenerate it after every dependency change.
- **Fonts**: listed with their licence texts in the notices file.
- **VitePress**: the five copied theme components name their origin and licence.
- **AI disclosure**: the README says the project is made by Niklas with substantial AI assistance (Claude) and that
  the copyright status of purely AI-generated material is unsettled in some jurisdictions.
- **The title**: "Space Game" is a working title. Search trademarks for the final title before any store release.
- **Publishing**: the repo on the VM keeps no remote (ADR-0008 and `CLAUDE.md`'s hard rule stand); it is published
  from elsewhere. Push explicit branches only (`main`, maybe `dev`), never `git push --mirror`: the repo has
  `refs/stash` and local sync refs that must not go out.

## Consequences

- New files: `LICENSE` (the split), `LICENSE-MIT`, `LICENSE-APACHE`, `content/LICENSE` (CC BY 4.0's notice and legal
  code), `THIRD_PARTY_NOTICES.md`, `README.md`, `wiki/.vitepress/theme/overrides/LICENSE-vitepress`.
- The local-only sibling repos (`../space-game-archive`, `../space-game-physics-bench`) and Niklas's private claude.ai
  artifact pages are named as unavailable to public readers (README, `CLAUDE.md`, `docs/concept-notes.md`); the
  records that link them stay as they are.
- Contributions from others, if they ever come, would need the same split stated (e.g. in a CONTRIBUTING note).
- Open for Niklas: the author identity in the copyright lines and git history (left as "Niklas"), the final title and
  its trademark search, and a `license` field in the pack manifest if mods should state theirs.
